# Flyback Power Converter PCB

## Overview
This repository contains the complete PCB design package for an isolated transformer-based flyback converter. It demonstrates primary-secondary isolation, snubber network design, and feedback regulation.

## Features  
- Isolated topology with a Wurth, high-frequency magnetic transformer.
- P-coil and S-coil return path (GND) isolation  
- RCD snubber circuit to provide safety against voltage spikes, caused by leakage inductance. 

## Repository Structure
- `/schematic`: KiCad schematic capture files.
- `/pcb`: Multi-layer board layout files.
- `/docs`: Datasheets, calculations, and fabrication outputs.
